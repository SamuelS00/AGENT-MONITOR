# SPEC 001: Product overview

## Objective and scope

Provide a local desktop monitor for AI CLI processes and sessions. It excludes orchestration or control of those tools.

## Requirements and rules

Show verified local activity, preserve source reliability and support later history. A missing field is unavailable, never zero.

## Use cases and acceptance

As a developer, I can open the app and distinguish active discovered work from unavailable metadata. Acceptance: no simulated execution is shown as real.

## Dependencies

Tauri, Rust collector, React UI and SQLite.
