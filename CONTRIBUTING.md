# Contributing

Use small conventional commits (`feat:`, `fix:`, `docs:`, `test:`, `chore:`) and branches named `feature/<topic>` or `fix/<topic>`. Keep adapter capability changes documented in `docs/architecture/integrations.md`.

Before opening a review, run the TypeScript and Cargo checks in the README. Tests and fixtures must label synthetic data clearly; the app UI must remain sourced from real collector data.
